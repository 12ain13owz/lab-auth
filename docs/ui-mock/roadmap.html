Feature-sliced roadmap

Each feature goes through the full slice before the next one starts: contract, migration, Express, tests, then the Angular screen. Next.js, NestJS, Go and Python repeat the finished slices later against the same contract.

Definition of done for every slice

1 · Contract

  • OpenAPI paths + error codes
  • Spectral lint passes

2 · DB

  • Up + down migration
  • Applies to all 4 DBs

3 · Express

  • Unit tests (services, policies)
  • Integration tests (repo + real Postgres)

4 · Contract-e2e

  • Black-box HTTP suite green
  • Includes the abuse cases

5 · Angular

  • Screen from this mock
  • Component tests + Playwright e2e

6 · Close

  • ASVS rows updated
  • Commit to develop

Gaps found in the current docs

G1
Next.js isn't mentioned

AGENTS.md says "Angular (one app)". Add apps/web-next and an ADR on whether it is a pure SPA client or uses Next.js server features (BFF).

G2
Email OTP vs verification link is undecided

Docs say "verification token"; you said OTP. Proposed open item O9. OTP needs an attempt cap; a link needs a long random token.

G3
No sessions table

Device list and "sign out this device" need user agent, IP and last-used per refresh family. Put them on a sessions row instead of repeating on every token.

G4
Missing endpoints

resend verification, change password, list/revoke sessions, re-auth, MFA setup/verify, admin. The Step 1 contract only lists 8 endpoints.

G5
Test strategy covers contract-e2e only

No mention of BE unit/integration tests, Angular component tests or browser e2e (Playwright). Add a testing section per app.

G6
Roadmap is layered at Steps 3–4

Step 3 builds register + login in Express before any FE. The slices above match your "BE then FE right away" rule.

G7
Email pipeline isn't designed

Templates, sending after commit, timing leaks, security notification emails, link origin from env.

G8
Security testing tools aren't in the plan

ZAP baseline, dependency audit and secret scanning fit F8. The ASVS matrix also lacks rows for session list, re-auth and MFA replay.

G9
Account lifecycle

Email change and account deletion aren't covered. Suggest marking them out of scope for v1 so they're a conscious choice.

Feature

F4 · Forgot / reset password

API

POST/api/auth/reset-password
{ "token", "password" }
→ 200 password changed
→ 400 { code: "RESET_TOKEN_INVALID" } // missing, used or expired
→ 400 validation (policy / breached)

Backend stores

  • password_reset_tokens.used_at (single use, in the same transaction as the password update)
  • users.password_hash, password_changed_at
  • Revoke every sessions row of the user
  • Send "password changed" email
  • audit_log: password_reset.completed

Security

  • Token in the URL: set Referrer-Policy: no-referrer on this route and don't load third-party resources here.
  • FE reads the token, then removes it from the address bar (history.replaceState).
  • Don't log the query string for this path.
  • Don't auto-login after reset (forces a fresh login + MFA).

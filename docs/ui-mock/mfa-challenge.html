Feature

F6 · MFA (TOTP)

API

POST/api/auth/mfa/verify
{ "mfaToken", "code" } | { "mfaToken", "recoveryCode" }
→ 200 { accessToken, … } + refresh cookie
→ 401 { code: "MFA_INVALID" }
→ 429

Backend stores

  • mfaToken: short-lived (5 min), purpose-bound, cannot be used as an access token. Signed JWT with typ=mfa or a row in mfa_challenges.
  • users.mfa_last_used_step: reject the same TOTP step twice (replay)
  • mfa_recovery_codes.used_at
  • sessions.mfa_at (step-up later)

Security

  • Allow ±1 time-step drift only.
  • Rate-limit attempts per mfaToken and per user.
  • Session is only created after MFA passes.

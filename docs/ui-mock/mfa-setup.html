Feature

F6 · MFA (TOTP)

API

POST/api/me/reauth
POST/api/me/mfa/setup
POST/api/me/mfa/enable
setup  → { otpauthUri, secret }     // pending, not active yet
enable { code } → { recoveryCodes: [10] }  // shown once
→ 400 { code: "MFA_INVALID" }

Backend stores

  • users.mfa_secret_enc: encrypted (AES-GCM, key from env). It must be readable to verify codes, so it can't be hashed.
  • users.mfa_enabled_at set only after the first valid code
  • mfa_recovery_codes: 10 × code_hash, used_at
  • sessions.reauth_at for "password confirmed in last 5 min"

Security

  • Generate the QR on the client from otpauthUri (no third-party QR service: it would see the secret).
  • Secret + codes: Cache-Control: no-store.
  • Email alert "two-step verification turned on".

Error envelope (contract)

{
  "message": "Too many requests",
  "timestamp": "2026-11-11T02:14:00Z",
  "code": "RATE_LIMITED",
  "requestId": "req_8c1f2a",
  "errors": [ { "field": "email", "code": "invalid" } ]  // 400 only
}

Rules

  • FE switches on code, never on message text.
  • requestId is shown to the user and written in logs; never stack traces.
  • 403 vs 404: for resources the user may not know exist (another user's session), return 404.
  • 429 includes Retry-After; FE shows the countdown from it.

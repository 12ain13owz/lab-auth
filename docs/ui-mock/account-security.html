     lastUsedAt, current: true|false }]

Backend stores

  • sessions holds everything this list needs: user_agent, ip, created_at, last_used_at, revoked_at, revoked_reason
  • "current" = session id inside the access token (sid claim)
  • Location: optional (GeoIP is extra scope). Can show IP only.

Security

  • Change password requires the current one (re-authentication).
  • DELETE session must check session.user_id = me (IDOR). Return 404 for others' sessions.
  • Revoking a session = revoke its refresh family; access token dies at expiry (~15 min). Document this trade-off.
  • Email "password changed" + "two-step turned off" alerts.

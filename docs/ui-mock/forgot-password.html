Feature

F4 · Forgot / reset password

API

POST/api/auth/forgot-password
{ "email" }
→ 202 always, same body, similar timing
→ 429 rate limited

Backend stores

  • password_reset_tokens: token_hash (SHA-256 of ≥ 256-bit random), expires_at (30 min), requested_ip
  • New request invalidates older unused tokens
  • audit_log: password_reset.requested

Security

  • Never say whether the email exists.
  • Send the email asynchronously (queue / outbox) so response time doesn't leak existence.
  • Build the reset URL from a configured APP_ORIGIN, never from the Host header (host-header poisoning).
  • Rate-limit per email and per IP.

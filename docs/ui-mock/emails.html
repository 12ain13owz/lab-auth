Mail pipeline

  • Dev: SMTP → mailpit (:1025), read at :8025. e2e tests read codes from the mailpit API.
  • Templates: plain text + HTML, inline CSS, no external images or tracking.
  • Send after commit (outbox table or in-process queue), so a slow SMTP doesn't change response timing.

Backend stores

  • Optional email_outbox: to, template, payload_json, status, attempts, sent_at
  • Payload never stores the plain OTP/token after send

Security

  • Links built from APP_ORIGIN env, never the request Host.
  • Escape display names in templates (HTML injection in email).
  • Code in subject line is convenient but visible on lock screens. Decide (O9).
  • "new-sign-in" alert: send only for a new device fingerprint (UA + IP range), or it becomes noise.
